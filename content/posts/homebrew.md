# Homebrew

## 설치

[Homebrew 공식 홈페이지](https://brew.sh/)

공식 홈페이지에서 제공하는 설치 방법을 따른다.

## Brew bundle 이용하기

```bash
# Brewfile 파일이 있는 경로에서 실행
brew bundle install
# 또는
brew bundle

# 파일 지정하기
brew bundle install --file ~/Downloads/Brewfile
```
