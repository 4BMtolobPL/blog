Kommit#

Kommit은 AI를 사용하여 Git 변경 사항(diff)을 분석하고, Conventional Commits 규격에 맞는 커밋 메시지를 자동으로 생성해주는 CLI 도구입니다.

주요 기능#

  • 🔍 Diff 분석: 스테이징된 변경 사항 또는 현재 작업 트리의 변경 사항을 분석합니다.
  • 📝 Conventional Commits: feat, fix, refactor 등 표준화된 커밋 타입을 자동으로 분류합니다.
  • 🏗️ 자동 커밋 및 푸시: 생성된 메시지로 즉시 커밋하거나 리모트 저장소에 푸시할 수 있습니다.
  • ✏️ 인터랙티브 편집: 커밋 전 생성된 메시지를 직접 수정할 수 있는 편집 모드를 지원합니다.
  • 🌐 다국어 지원: 한국어와 영어 메시지 생성을 지원합니다.
  • 🤖 다양한 AI 프로바이더: Ollama 및 LM Studio와 같은 로컬 LLM을 지원하며, 커스텀 호스트와 포트 설정이 가능합니다.

설치 방법#

1. Homebrew를 이용한 설치 (macOS)# 

brew install 4BMtolobPL/homebrew-tap/kimtalmo-kommit

2. Cargo를 이용한 설치 (Rust)#

Rust 툴체인이 설치되어 있어야 합니다.

# 저장소 클론
git clone https://github.com/4BMtolobPL/kommit.git
cd kommit

# 빌드 및 설치
cargo install --path kommit

사용법#

Kommit은 두 가지 주요 서브커맨드를 제공합니다: run (메시지 생성) 및 config (설정 관리).

1. 커밋 메시지 생성 (run)#

스테이징된 변경 사항 또는 작업 트리의 변경 사항을 분석하여 커밋 메시지를 생성합니다.

# 기본 실행 (설정된 기본값 사용)
kommit run

# 스테이징된 변경 사항만 분석하고 생성된 메시지 편집
kommit run --staged --edit

# 생성 후 즉시 커밋 및 푸시
kommit run --commit --push

# 특정 언어, 프로바이더, 모델 및 커스텀 서버 주소 지정
kommit run --lang ko --provider ollama --model gemma2 --host 127.0.0.1 --port 11434

run 주요 옵션#

옵션 설명 기본값
--staged 스테이징된 변경 사항(git diff --staged)만 분석합니다. false
-m, --model 사용할 LLM 모델 명칭을 지정합니다. gemma4
-l, --lang 메시지 언어를 지정합니다. (en, ko) en
--provider AI 프로바이더를 지정합니다. (ollama, lm-studio) ollama
-s, --stream 스트리밍 응답 활성화 여부를 지정합니다. false
-t, --think 추론(Thinking) 레벨을 지정합니다. (true, false, low, medium, high) false
-c, --commit 메시지 생성 후 자동으로 git commit을 수행합니다. false
-p, --push 커밋 후 자동으로 git push를 수행합니다. false
-e, --edit 커밋 전 사용자가 메시지를 수정할 수 있도록 편집기를 엽니다. false
--host LLM 서버의 호스트 주소를 지정합니다. None
--port LLM 서버의 포트 번호를 지정합니다. None

2. 설정 관리 (config)#

매번 명령행 옵션을 입력하지 않도록 기본 설정을 관리할 수 있습니다.

# 현재 설정 및 설정 파일 경로 확인
kommit config show

# 기본 모델 변경
kommit config set model llama3

# LLM 서버 주소 설정
kommit config set host 192.168.1.10
kommit config set port 11434

# 설정 디렉토리 열기
kommit config open

사전 요구 사항#

이 앱은 외부 또는 로컬 LLM 프로바이더를 통해 메시지를 생성합니다. 선택한 프로바이더의 서비스가 활성화되어 있고 API 접근이 가능한 상태여야 합니다.

  • 로컬 프로바이더 (Ollama, LM Studio 등): 해당 서비스가 로컬에서 실행 중이어야 하며, 기본 포트(11434, 1234 등)가 열려 있어야 합니다.
  • 모델 준비: 사용하려는 모델이 해당 프로바이더에 이미 설치 또는 다운로드되어 있어야 합니다.
  • 네트워크 설정: 향후 추가될 클라우드 기반 프로바이더의 경우 API 키 또는 인증 설정이 필요할 수 있습니다.

향후 계획 (Roadmap)#

Kommit은 지속적으로 기능을 확장할 예정입니다:

  • 자동 커밋 및 편집 모드: 생성된 메시지로 즉시 커밋하거나, 커밋 전 사용자가 메시지를 수정할 수 있는 인터랙티브 모드 추가
  • 설정 파일 지원: 매번 옵션을 입력하지 않아도 되도록 config.toml을 통한 기본값 설정 기능
  • 커스텀 프롬프트 템플릿: 조직 내의 특정 커밋 규칙을 적용할 수 있는 사용자 정의 템플릿 기능
  • 성능 최적화: 실시간 메시지 생성을 위한 스트리밍(Streaming) 및 추론(Thinking) 옵션 지원
  • 프로바이더 확장: OpenAI, Anthropic 등 클라우드 기반 LLM 서비스 지원 및 API 키 관리 기능
